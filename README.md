# 가을 옷장

12–13세 발달장애 학생을 위한 가을 옷차림 학습 시제품. 설치 의존성 없이 HTML, CSS, JavaScript로 실행합니다.

## 실행

`npm start` 후 http://localhost:5173 에 접속합니다. 같은 Wi-Fi의 태블릿에서는 실행 컴퓨터의 로컬 IP와 5173 포트로 접속할 수 있습니다. 방화벽 및 네트워크 설정에 따라 접속이 제한될 수 있습니다.

`npm test`로 점수 규칙을 검증합니다.

## 규칙

- 선선한 가을 소풍 상황을 기준으로 긴팔·긴바지·가벼운 재킷을 적절한 옷으로 설정했습니다. 실제 수업 전에 교사가 상황과 옷의 적절성을 검토해 주세요.
- 현재 입은 윗옷 ±40점, 아랫옷 ±30점, 겉옷 ±30점. 미선택은 0점. 모두 적절하면 100점입니다.
- 캐릭터 영역 어디에 놓아도 옷이 입혀집니다. 영역 밖 드롭·취소는 점수에 영향을 주지 않습니다.
- 포인터 이벤트를 사용해 마우스·터치·펜으로 끌 수 있습니다. 키보드는 Tab 및 Enter/Space로 선택합니다.
- 선생님 설정에서 눌러 입히기·점수 숨기기를 선택할 수 있습니다. 설정만 기기에 저장하며 학생 식별정보 및 학습 기록은 저장하지 않습니다.
- 한국어 음성은 기기의 브라우저 음성 합성을 사용합니다. 한국어 음성 설치·지원 상태에 따라 재생 여부가 달라질 수 있습니다.

## 구성

`game.js`: 의상 데이터와 점수 계산. `art.js`: 캐릭터와 의상 SVG. `app.js`: 입력·화면·음성. `tokens.css`: 색상. `styles.css`: 반응형 화면.

현재는 웹 시제품이며 홈 화면 설치/PWA 및 서비스 워커 기반 오프라인 지원은 후속 단계입니다.

## 적용된 원본 에셋

사용자가 제공한 macrovector / Freepik EPS 원본 4종(42247, 42234, 42244, 42250)을 사용합니다. 무료 다운로드에 포함된 라이선스에 따라 화면 하단에 `Designed by macrovector / Freepik`과 링크를 표시했습니다. 원본 ZIP·EPS는 배포하지 않고, 게임에 필요한 가공 SVG만 사용합니다.

- 남자: 일반옷의 몸체·셔츠·긴바지·니트·패딩, 여름옷의 민소매·반바지.
- 여자: 일반옷의 몸체·셔츠·긴바지, 스포츠 세트의 민소매·반바지·집업. 패딩은 남자 일반옷 원본을 체형에 맞춰 공용으로 사용합니다.
- 신발은 기본 착용이며 점수에 영향을 주지 않습니다.
- 캐릭터 선택 시 현재 옷차림과 점수가 초기화됩니다.
- SVG 제작 과정은 `scripts/extract-assets.py`에 남겼습니다. 개발용 Ghostscript와 PyMuPDF는 에셋 가공 때만 사용하며 게임 실행에는 필요 없습니다.
- 캐릭터 표정은 원본을 유지합니다. 선택에 대한 반응은 짧은 문장과 음성으로 제공합니다.
